# Heavenly Hosts — Hosting & Decor Atelier

## 🌸 Project Overview

This is a complete, self-contained website contained within a single file named `Heavnly hosts web.html`. It features editorial typography, organic section transitions, interactive 3D elements, floating rose petals, and a dynamic pricing calculator tailored for intimate luxury gatherings.

## ✨ Key Features

1. **Editorial Botanical Hero:** A lush frame featuring soft pink heirloom roses, white peonies, anemones, cascading eucalyptus, and floating blush rose petals.

2. **Official Wreath Logo:** Features an olive branch wreath logo with elegant script typography in both the header and footer.

3. **The Garden Walk (Interactive Milestone Journey):** A scroll-driven pathway guiding visitors through your welcome story, fine art prints, and 3D frosted glass features.

4. **Interactive Hotspot Picnic Preview:** An immersive photo showcase where visitors can click glowing pins to explore styling details in a slide-out drawer.

5. **Editorial Package Tiers:** Interactive pricing cards with a guest slider (up to 20 guests) and custom price stepping.
